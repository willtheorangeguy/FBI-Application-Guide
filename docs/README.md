# FBI Application Guide — Documentation

A compiled reference for the FBI Special Agent application process. It is a document
collection, not software — nine folders of `.docx` and `.pdf` files, one folder per stage.

```
FBI-Application-Guide/
├── docs/
│   ├── README.md          this page
│   ├── usage.md           finding the right stage
│   ├── architecture.md    how the collection is organised
│   ├── faq.md             is this official, how current is it
│   └── roadmap.md         gaps and non-goals
├── 0 - Title and Contents
├── Step1 … Step9          one folder per stage
├── images/                illustrations
├── LICENSE.md             MIT, for the compilation
└── CONTENT_LICENSE.md     for the documents
```

## Pages

- [Usage](./usage.md) — which folder covers which stage

## Read this first

**This is unofficial.** It is a personal compilation of publicly available federal material,
not produced or endorsed by the FBI or any US government agency.

**It may be out of date.** Application requirements, testing standards, and fitness scoring
change. Nothing here updates itself, and nothing records when each document was collected.
Always confirm against [fbijobs.gov](https://fbijobs.gov/) before relying on it.

**The licensing needs review.** The documents originate with federal agencies rather than with
this repository, so the content licence does not straightforwardly apply to them. See
[`internal/known-issues.md`](./internal/known-issues.md).
