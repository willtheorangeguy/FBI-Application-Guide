# FBI Application Guide — Usage

## Getting it

Download the repository as a ZIP, or clone it. Everything is a document — there is nothing to
install and nothing to run.

Start with **`0 - Title and Contents`** for the overview.

## The stages

Folders follow the application process in order:

| Folder | Covers |
|---|---|
| `Step1` | Applying and submitting, the Federal Resume Guide, eligibility, FAQ |
| `Step2` | Testing overview |
| `Step3` | Citizenship — naturalisation steps, checklist, eligibility worksheet, N-400 instructions |
| `Step4` | Meet and greet session |
| `Step5` | Testing overview |
| `Step6` | Testing overview, training tips, events and scoring |
| `Step7` | Conditional appointment offer |
| `Step8` | Social media guidelines |
| `Step9` | General overview, training academy overview |

Three separate folders carry a "Testing Overview" — Steps 2, 5, and 6 — because testing occurs
at more than one point in the process. They are not duplicates of each other.

## Two formats

Every document exists as both `.docx` and `.pdf`:

- **`.docx`** — editable, so you can annotate, fill in worksheets, or adapt a resume template.
- **`.pdf`** — fixed layout, for reading and sharing.

The `.docx` copies are the reason the Step 3 citizenship worksheets and the Federal Resume
Guide are useful rather than merely readable.

## Working through it

The numbering is `<step>-<item>`, so `1-2` is the second document of Step 1. Reading in order
tracks the process, though most people will only need the stage they are at.

## Verify before relying on it

Requirements change and nothing here updates automatically. Before acting on eligibility
criteria, fitness scoring, or form instructions, check the current version at:

- [fbijobs.gov](https://fbijobs.gov/) for the application and testing
- [uscis.gov](https://www.uscis.gov/) for naturalisation and the N-400

See [FAQ](./faq.md).
