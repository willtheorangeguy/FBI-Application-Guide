## Key Features

- Nine folders, one per stage of the application process, in order.
- Every document in both `.docx` and `.pdf` — editable, and portable.
- Covers applying, eligibility, testing, citizenship, fitness, and the academy.
- Includes the US Federal Resume Guide and USCIS naturalisation materials.
- Readable offline; no tooling required beyond a word processor or PDF reader.

## Usage

Download the repository and open the folder for the stage you are at. See [`docs/usage.md`](docs/usage.md).
